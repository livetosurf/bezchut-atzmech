# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Project Overview

This is a **static HTML site** for "בזכות עצמך" (https://bezchut.co.il) — a Hebrew women's empowerment content portal, deployed with GitHub Pages from the `main` branch (pushing = deploying). Pages are self-contained `.html` files with embedded CSS and JavaScript; there is no framework, only small Node build scripts.

**The homepage is `index.html`**, served at `https://bezchut.co.il/`. `bezchut-atzmech.html` is only a redirect stub to `/` kept for old links — **never edit it; edit `index.html`**. Every "home" link in the site is the root-absolute `href="/"`.

## Building and previewing

```bash
node build.js              # rebuild everything from posts-data.js and validate (run before every commit)
node tools/dev-server.js   # local preview at http://localhost:4173
```

`build.js` runs, in order: `generate-posts.js` → `tools/build-listings.js` → `tools/generate-sitemap.js` → `tools/validate-articles.js`, and stops on the first failure. Do not push when it fails.

Because home links are `/`, opening files straight from disk (`file://`) does not navigate correctly — use the dev server.

## Content workflow (articles)

**[posts-data.js](posts-data.js) is the single source of truth.** Every article's metadata, full body (`content`), featured image (`image`), extra structured data (`ld`), file path (`url`) and optional `updated` date live there. Everything below is a build artifact derived from it:

| Artifact | Built by |
|----------|----------|
| Article pages in `posts/` | `generate-posts.js` |
| Post lists on the homepage, the six older category hubs and `all-posts.html`; anchors + titles on the newer hubs | `tools/build-listings.js` |
| `sitemap.xml` | `tools/generate-sitemap.js` |

To add an article: add a posts-data.js entry (next id, cat, catColor, url, image, content, optional ld) and run `node build.js`. On the five newer hubs (see below) also add a card by hand. Full checklist: `.claude/skills/verify-article/SKILL.md`.

Rules:
- **Never edit files in `posts/` by hand** — the next build overwrites them. Global changes (nav, footer, webhook, schema, layout) go in the template inside `generate-posts.js`, once.
- **Never hand-edit the embedded `allPosts` / `posts` arrays** in hub pages, `index.html` or `all-posts.html` — `build-listings.js` regenerates them.
- When you change an existing article's title or content, set `updated:'YYYY-MM-DD'` on its entry; it drives `dateModified` in the schema and `lastmod` in the sitemap.
- Redirect stubs (retired duplicates in `posts/`, `bezchut-atzmech.html`, `baalat-haesek.html`) are meta-refresh pages; the sitemap generator skips them automatically.

### Category hubs

Categories are defined in `CAT_META` at the bottom of posts-data.js; each has a hub page. Two generations of hub exist:

- **Older hubs** (JS-rendered from an embedded `allPosts` array): `esek-viyazmanut`, `kaspim-vefinansim`, `marketing-digital`, `briut-veravaha`, `manhigut-nashit`, `lmida-vetzmikha`. Fully regenerated by `build-listings.js` — featured card, filter tags, static pre-rendered cards.
- **Newer hubs** (static hand-written cards): `mosach-nashim`, `hasava-miktzoit`, `gerushin-atzmaut`, `diur-nadlan`, `zchuyot-avoda`. Cards are written by hand; `build-listings.js` only wraps each card title in a real `<a href>` and syncs the title text.
- `moadonei-ai.html` is an affiliate page with no articles.

Adding a category also needs a `CAT` config entry in `generate-posts.js` (slug, page, colors, images, altPrefix) and a card in the `#categories` grid of `index.html`.

## SEO invariants (the validator enforces these)

- Every article must be reachable through a real `<a href>` from its category hub. Google does not follow `onclick` navigation — never link articles with `onclick` alone.
- Inline scripts of root pages must parse. A syntax error in a hub's script silently empties its article grid.
- Internal links must resolve; JSON-LD must parse (inside JSON-LD text use `״`, never a straight `"`).
- Canonical host is `https://bezchut.co.il`; the homepage canonical is the bare root.
- `og-image.jpg` is rendered from `og-image.svg` (1200×630). Social platforms do not accept SVG.

### Design System (shared across all portal pages)

- **Fonts:** `Assistant` (body), `Heebo` (headings/logo), loaded from Google Fonts
- **Brand colors:** `--primary: #6B2D7C` (purple), `--accent: #C9A84C` (gold), `--bg: #FBF6FE`
- **Direction:** `dir="rtl"` — all content is Hebrew right-to-left
- Category colors are defined per-category in posts-data.js (`catColor`) and in the `CAT` config of `generate-posts.js`
